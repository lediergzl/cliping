# Música para tus clips

Sube aquí tus pistas (`.mp3`, `.m4a`, `.aac`, `.wav`, `.ogg`, `.opus`, `.flac`).
En el panel del userscript, en **🎵 Música de fondo**, escribe solo el nombre
del archivo (por ejemplo `tema.mp3`). No uses rutas ni subcarpetas.

Usa música de la que tengas derechos o licencia: el clip se publica en un Release.
